# 美心 AI 行政助手数据库设计

状态：逻辑设计基线，实施时由 Alembic 迁移落库。生产数据库为 PostgreSQL；SQLite 仅用于开发和测试。

## 1. 通用约定

- 主键 `id`：UUID；业务编号单独设置唯一约束。
- 时间：`TIMESTAMPTZ`，统一保存绝对时间，展示时转换为 `Asia/Shanghai`。
- 日期：无时间概念时使用 `DATE`。
- 金额：`NUMERIC(12,2)`；课时：`NUMERIC(8,2)`；禁止 `FLOAT`。
- 状态字段使用受控字符串并在应用层枚举、数据库层约束。
- 业务表默认含 `created_at`、`updated_at`；流水表含 `created_by`。
- 历史业务数据不物理删除，使用 `status`、`voided_at` 或冲正记录。

## 11. 关键索引和一致性

- 为所有外键建立索引；对学生姓名/规范化手机号、排课时间、签到确认状态、账户余额、缴费日期、提醒状态建立查询索引。
- `attendance_records(schedule_id, student_id)`、`teacher_lesson_records(schedule_id)`、课消 `attendance_id` 设置唯一性以防重复。
- 课消事务锁定 `lesson_accounts` 行，插入流水并更新余额后一次提交；失败全部回滚。
- 每日对账：`balance_units = SUM(lesson_transactions.units WHERE posted)`；不一致时生成高优先级提醒，不自动改账。
- PostgreSQL 使用 JSONB；SQLite 测试通过 SQLAlchemy JSON 抽象适配，不编写依赖 SQLite 特性的生产逻辑。

## 12. 数据迁移和保留

真实 Excel 导入先在测试环境演练并输出差异报告，负责人确认后再进入生产。每次结构迁移前备份；迁移脚本必须支持从空库顺序执行。缴费、课消、教师课时和工资记录按财务与劳动资料要求制定保留期；具体年限需负责人结合当地法规确认。
